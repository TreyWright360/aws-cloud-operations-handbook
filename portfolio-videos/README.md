# Portfolio video scripts

Shot-by-shot scripts for the 7-video job-search series. Distinct from [`videos/`](../videos), which covers standalone incident-runbook walkthroughs — these scripts are the recruiter-facing portfolio pitch, built entirely from real, evidenced lab work in [`evidence/`](../evidence).

## Recording order

Record in this order — later scripts assume vocabulary and beats established earlier, and video 1 is cut down from the deep-dive footage, not filmed first:

1. [02-handbook-tour.md](02-handbook-tour.md)
2. [03-safe-deployment-workflow.md](03-safe-deployment-workflow.md)
3. [04-multiaz-deep-dive.md](04-multiaz-deep-dive.md)
4. [05-iam-governance-deep-dive.md](05-iam-governance-deep-dive.md)
5. [06-dataops-deep-dive.md](06-dataops-deep-dive.md)
6. [07-ecs-bedrock-deep-dive.md](07-ecs-bedrock-deep-dive.md)
7. [01-portfolio-overview.md](01-portfolio-overview.md) — record last, cut down from 2–7's footage

## Companion tool

The [Failure Map Studio](https://claude.ai/artifact/EutuTACQxeuYEwNqtbWKcb) has staged diagrams per project matching scripts 4–7 — useful as an on-screen visual while recording, or for reviewing the beats before filming.
