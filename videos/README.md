# Video and LinkedIn publishing guide

For each episode, open with one operational question, show the user-visible symptom, compare the plausible fault domains, make one decisive diagnostic choice, and finish with a verified recovery request. Say plainly that the exercise is a controlled AWS lab simulation. Link the matching handbook article; that article links the code and dated evidence.

Before publishing, check that the screen recording hides account IDs, credentials, private endpoints, and any unrelated browser tabs. If a step was not demonstrated, describe it as a proposed production improvement.
